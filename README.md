# Playwright-project-IT23683136

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yashWeerasinghe/Playwright-project-IT23683136.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Playwright-project-IT23683136
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running Tests

1. To execute the test cases, run the following command:
   ```bash
   python test_automation.py
   ```

2. Ensure that all necessary configurations are set up before running the tests.

## Notes

- Make sure Python is installed on your system. You can download it from [python.org](https://www.python.org/).
- Use a virtual environment to avoid dependency conflicts.
